# 架构与技能规划

网页与 Python FastAPI 后端来自同一源；单个后端进程拥有一个后台调度器，SQLite WAL 保存任务，FFmpeg 检查视频和生成零费用测试视频。未来 App 可调用相同 API。服务器只做调度与保存，不运行生成模型，不需要 GPU。

## 两种工作流

GitHub Actions 构建、检查和部署软件。用户点击生成时，由轻量云应用调度模型；不为每次图片调用 GitHub Actions。首版明确编排，不额外调用 Agent 决定路由。

## 技能与模板

|模块|规则/AI|实现|
|---|---|---|
|input_validate|规则|角色、尺寸、数量、身份声明、模型能力、预算|
|garment_present|图像AI|独立商品图模板；保留上游结果和原素材|
|outfit_image|图像AI|素材角色顺序和模板提示词一次合成|
|reference_board|普通图像处理|按编号排列，用于图像接口对照；禁止直接送普通视频首帧|
|human_review|人工|服装/身份/动作1～5分；可交付判断；账单核对|
|outfit_video|视频AI|完整Look到视频；动作迁移需额外动作视频|
|asset_finalize|规则|转存、实际文件检查、私人下载、来源记录|
|garment_extract|后续|服装分割和生成补全分开评估|
|outfit_3d|后续|独立生成与文件导出，不混同视频拖动|

每个模板保存 ID、版本、类型、技能、提示词、避免项和验收标准。输入素材通过 asset_id 与 role 关联。任务冻结模板/模型快照、素材 SHA256、输入参数与工作流版本。编辑模板创建新版本，旧实验不变。避免项追加到统一提示词；万相Animate没有提示词参数，明确不传。

## 任务与恢复

`queued → submitting → polling → saving → succeeded`

- `submitting` 先落盘再发请求；网络中断、5xx或服务重启进入 `uncertain`。绝不自动再次 POST，核对供应商控制台后填写任务编号恢复查询。
- 已获得供应商 task ID 后，查询暂时失败延迟继续查询；2小时后暂停。恢复查询不生成新任务。
- `saving` 前保存供应商结果地址，仅在私有数据库中留存。保存失败进入 `save_failed`；恢复仅下载，已保存的部分结果不会重新生成。
- 模型报告失败进入 `failed`，主动修改输入重新生成是新任务，需要新预算与确认。
- 创建任务使用 Idempotency-Key 和请求哈希。同一编号重复提交返回同一任务；编号用于不同参数时拒绝。
- 图片的人工结论必须为 pass，才可作为关联视频输入。手动上传的完整Look由测试者明确确认。模拟图不能进入真实视频任务。

只部署一个 Uvicorn worker；扩容需要数据库任务租约与分布式队列，不能简单增加进程数。

## 费用与统计

默认模拟模式，不调用模型。真实模式需要服务器总开关、供应商Key、逐次付费确认和预算预占。按上海日期控制每天真实任务数量与预算；记录创建后即占用，失败或结果未知也保留，直到人工对账。预占额度不是上游的费用硬上限。

账单金额默认未知；不会把 token 数、积分或估价伪装成实际人民币费用。人工填写 actual_cny，原始返回的可用用量另记。成功交付成本仅在真实任务账单完整且存在人工合格结果时计算：全部真实模型费用 / 合格结果数。基础设施费用尚未自动摊销，商业决策前需另加。

## 隐私与测试边界

仅单个私人测试空间，无多用户隔离或支付模块。密码与会话签名服务端验证，CSRF与同源校验；媒体下载需登录，模型取材使用短期签名地址。访问日志关闭，导出不带签名URL、Key或供应商私有结果地址。图片经解码校验、去除元数据并保存为PNG；这不是原始字节文件归档。动作视频实际探测尺寸和时长，图片支持JPEG/PNG/WebP，暂不支持HEIC。

结果下载拒绝非HTTPS、内网地址和不安全跳转，访问公网结果不携带供应商鉴权。首次公网部署必须设置密码、会话密钥并关闭 DEV_MODE。拒绝Seedance本人模式和来源含identity的生成图；上传者仍须确认默认模特素材适用于供应商政策，平台不会自动完成真人认证。

被任务引用的素材不能直接删除；模拟记录可删除后再删素材，真实费用记录保留。生产版需增加独立的私人资产删除/保留政策、空间配额和多用户访问控制。
