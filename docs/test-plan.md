# 测试计划

## 阶段0：无需真实Key

运行后端和浏览器测试。必须覆盖：幂等重复提交、参数不同但编号相同的拒绝、并发预占、图片确认后才生成视频、浏览与下载不创建任务、模型/模板快照、提交不确定与服务重启保护、保存失败仅恢复下载、鉴权/CSRF、过期素材签名、敏感字段与导出脱敏。

网页的“模拟故障测试”：none为正常；generation模拟上游失败；submit_unknown模拟提交后失联；save_once模拟文件保存一次失败。模拟视频为静态帧，用来验证任务、实际MP4交付、播放和下载，不作为质量评估。

## 阶段1：逐个平台少量真实接入

人工核对账号余额、后付费开通、国内端点与地域、真实模型ID、素材授权、输入格式与参数。预览请求，再明确确认真实调用。每个平台先少量提交，不自动运行批量矩阵。记录任务编号、排队时间、请求ID、输出质量、账单用量与实际人民币金额。

## 阶段2：固定穿搭素材

六套服装：纯色、印花、格纹、外套叠穿、裙装、鞋子细节。两条图像路线各重复两次，计划24张。原生多图优先，Qwen3图限制可测试参考板。固定同一模板、素材与seed；不能承诺相同seed严格复现。

每次填写相同group标签；结果对比页最多展示四个结果。检查单品、主色、图案、领口、裤型、鞋子、身份。明显改衣服、漏单品或改印花直接判失败，不只给“画面好看”的分数。

## 阶段3：确认图片到视频

六张合格图片，万相首帧、万相动作迁移、可灵动作控制、MiniMax H3四种配置各重复两次，计划48条。先小幅摆姿、45度转向；不能在背面不明素材上宣称360度还原。平台最短时长按档案选择，裁短不会减少已生成费用。Vidu和Seedance作为第二轮对照。

## 阶段4：完整场景与商业测算

默认模特和本人模式分开；Seedance本人授权未接入前不参加本人测试。验证换衣服的新图片任务、换动作复用图片、视频失败续接、下载、页面关闭后任务继续。逐条核对账单，包含API成功但视觉不合格及失败费用。模型成功交付成本之外，再加入服务器、存储、带宽、人工检查等成本，才决定订阅额度。

80%人工合格率只作小样本筛选假设，不是已证明的生产成功率。真人精确合身、自拍拆衣、衣服背面补全、真实3D和打印文件分别建立后续测试，不混入首版承诺。
